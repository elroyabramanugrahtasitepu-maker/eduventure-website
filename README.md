# Eduventure Abroad Website

A web-based platform developed for Eduventure Abroad to provide information about educational programs, language learning, and study-abroad services.

## Overview

Eduventure Abroad Website is a dynamic web application designed to provide information about Eduventure's educational programs and services.

The website includes a public-facing interface and an administrative dashboard for managing website content.

## Features

- Responsive landing page
- Program information
- Company profile
- Gallery
- Testimonials
- Dynamic content management
- Admin dashboard
- Background and banner management
- Gallery management
- Program management
- Database integration

## Technologies

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP
